# Quizzz Buzz — Android Quiz App

Tech stack: Android Studio, Java, XML

## Open & run
1. Android Studio -> File > Open -> select this `QuizzzBuzz` folder.
2. Let Gradle sync finish (needs internet the first time).
3. Press Run on an emulator or a connected phone.

## Features (matches the Task 4 checklist)
- Welcome screen with Start button
- Question screen: question text, 4 radio-style options, "Question X of 10" counter
- 15-question pool, 10 picked at random in shuffled order each run (options shuffled too)
- Instant feedback: correct answer green, wrong pick red
- Next / Finish button, live score tracking
- Results screen: total score, correct, incorrect, Restart Quiz button
- Custom launcher icon (adaptive + legacy) from the supplied image
